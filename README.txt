Frisch Family Farms - hosted app package (version 35)

Files: index.html (the app), manifest.webmanifest, sw.js (offline), icon-*.png, CNAME (app.frischfarms.com), .nojekyll
Upload ALL files (including the hidden .nojekyll) to the root of a GitHub repo, then turn on GitHub Pages
(Settings > Pages > Deploy from a branch > main / root). Then add the DNS record described in the chat.
Your data is stored on the phone (IndexedDB + localStorage). Use Settings > Save backup file regularly.
